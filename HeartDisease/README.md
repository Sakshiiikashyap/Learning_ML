# ❤️ Heart Disease Predictor

This project predicts the likelihood of heart disease using Machine Learning models.

## 📌 Features
- Data Cleaning & Preprocessing
- Feature Scaling
- Multiple ML Models:
  - Logistic Regression
  - KNN
  - Naive Bayes
  - Decision Tree
  - SVM

## 🧠 Models Used
- Logistic Regression
- K-Nearest Neighbors
- Gaussian Naive Bayes
- Decision Tree
- Support Vector Machine

## ⚙️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib & Seaborn

## 📊 Results
Compared multiple models and selected the best based on accuracy.

## 🚀 How to Run
1. Clone the repo
2. Install dependencies:
   pip install -r requirements.txt
3. Run the model or app:
   python app.py
